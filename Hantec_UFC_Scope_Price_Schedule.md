# Hantec × UFC — Scope & Price Schedule (per film)

**Purpose:** every scope item carries its own price, so any line can be traced back in a post-completion conversation. If the client says *"you didn't deliver X — what did I pay for it?"*, the answer is **one row**, not a recalculation.

**How to read it in a dispute:**
- **Production (shared capture)** is incurred once the shoot happens — it is **not refundable per output**; it's the cost of getting the material. Each sub-line is still itemised so a *missing capture* (e.g. the trader world) maps to a number.
- **Deliverables (post)** are **output-specific and allocable** — this is the layer that gets credited/varied if a specific output is dropped, added or disputed.
- Costs reconcile to Ayham's V02 totals; this view re-cuts the same money **by scope** instead of by resource.
